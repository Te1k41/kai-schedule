## Weekly Progression Guide
| Week | Phase | Rounds | RPE | Key Focus |
|------|-------|--------|-----|-----------|
| 1-2 | Adaptation | 2 | 5-6 | Form, motor learning — no changes to current program |
| 3-6 | Accumulation | 3 | 6-7 | Add pull pattern (reverse snow angel/band row); reps climb via double progression |
| 7-9 | Intensification | 3 | 7-8 | Advance each exercise one difficulty rung; add tempo/unilateral variants |
| 10 | Deload | 2 | 4-5 | 50% volume cut, recovery, no intensity pushes |
| 11-12 | Re-accumulation | 3 | 6-7 | Consolidate new baseline before next cycle |
| 13+ | Cycle repeats | 2→3 | 5-8 | Restarts at Week 13's harder baseline (e.g. knee/full push-up instead of wall push-up) |

Walk days (Tue/Thu/Sat/Sun) are unchanged throughout all 12 weeks — this program only periodizes the Mon/Wed/Fri circuit.
