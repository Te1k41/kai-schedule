# Training Program Design

## Profile
| Item | Value |
|------|-------|
| Goal | Recomposition (fat loss priority + muscle retention/build) |
| Experience | True beginner — 0 months structured training |
| Available Time | 3 sessions/week (Mon/Wed/Fri), ~25-30 min/session, 18:30-19:00 |
| Equipment | Bodyweight-only. Resistance band optional (low-risk, silent). No free weights — fragile home. |
| Injury History | None reported. Default beginner precautions apply (joint-friendly progressions, RPE-capped, zero jumping/plyometrics — protects joints and floor/neighbors). |
| BMI | ~30.1 (obese range) — fat loss is the primary driver; protein + resistance training preserve muscle during the deficit. |

## Program Overview
- **Total Duration**: 12-week macrocycle (repeats at a harder baseline from Week 13 — see below)
- **Split**: Full Body ×3/week (same session each training day — this is NOT an A/B split; volume/difficulty progress week-to-week, not day-to-day)
- **Weekly Frequency**: 3 training sessions (Mon/Wed/Fri) + existing daily walk days unchanged (Tue/Thu/Sat/Sun)
- **Session Duration**: 25-30 min including warm-up, run as a circuit (rounds), not straight sets, to hit the time cap

## Periodization Plan
| Phase | Duration | Goal | Volume | Intensity | Notes |
|-------|----------|------|--------|-----------|-------|
| Adaptation | Weeks 1-2 | Motor learning, tendon/joint adaptation | 2 rounds/session (as in current schedule.html) | RPE 5-6 | **No new exercises.** Exact current "Full-Body A" circuit. Pure form focus. |
| Accumulation | Weeks 3-6 | Work capacity, close movement-pattern gap | 3 rounds/session | RPE 6-7 | Add 3rd round. Introduce Reverse Snow Angel (band Row if available) for the missing pull pattern. Double progression drives rep increases. |
| Intensification | Weeks 7-9 | Step up exercise difficulty | 3 rounds/session, reps reset lower on new variation | RPE 7-8 | Progress each exercise one rung on its difficulty ladder (e.g. wall push-up → incline push-up). Add tempo (3s lowering) and unilateral variants. |
| Deload | Week 10 | Recovery before next block | 2 rounds/session (50% volume cut) | RPE 4-5 | Drop back one difficulty rung if needed. No PRs, no rep-maxing. |
| Re-accumulation | Weeks 11-12 | Consolidate new baseline | 3 rounds/session | RPE 6-7 | Bridges into Week 13, which restarts the 12-week cycle at the harder baseline (e.g. knee/full push-up instead of wall push-up). |

Bodyweight training has no external load, so "intensity" here = RPE + position on each exercise's difficulty ladder, not %1RM. Weekly volume increases stay ≤10%, difficulty-rung advances only happen via the double-progression rule below (never mid-week, never more than one rung per progression event).

## Progressive Overload Strategy
- **Weekly progression rate**: Reps/hold-time first (double progression, see below), then round count (2→3 rounds, once — in Week 3), then exercise-difficulty rung (never more than once per exercise per 3-4 week phase), then rest reduction (last resort, only to protect the 30-min cap). No added load exists in this program — skip that overload variable entirely.
- **Double progression per exercise**: each exercise has a rep window (e.g. push-up progression = 10-15 reps). Hit the top of the window for all rounds across 2 consecutive sessions → advance to the next difficulty rung and reset to the bottom of the new window. Example: Wall Push-up 10→15 reps ✕2 sessions → Incline Push-up @ 10 reps.
- **Difficulty ladders** (advance one rung at a time, only via the rule above):
  - Push: Wall push-up → Incline push-up (counter/table) → Knee push-up → Full push-up
  - Squat: Assisted squat (holding support) → Bodyweight squat → Tempo squat (3s down) → Split squat (rear foot on chair)
  - Hinge: Glute bridge → Single-leg glute bridge → Hip thrust (shoulders/feet elevated on chair, chair against wall)
  - Pull: Reverse snow angel (prone Y-T-W raise) → Band row (if band available) → Band row w/ pause
  - Back extension: Superman hold → Superman alternating arm/leg raise → Superman pulses
  - Core: Dead bug → Dead bug slow tempo (4s) → Hollow body hold (short holds, beginner-scaled)
  - Isometric: Wall sit → Wall sit w/ heel raise → Single-leg-assisted wall sit
- **Plateau management**: 3-4 sessions with no rep/hold-time increase at the same rung → do not force a difficulty jump; instead hold volume flat for 1 week, check RPE and sleep/soreness, then retry. If still stuck, treat as an early deload trigger.
- **Deload criteria**: scheduled at Week 10 (beginner deload cadence = every 8-12 weeks per periodization-engine guide). Trigger an *unscheduled* deload early if: 3-4 consecutive weeks of stagnation, joint pain, or motivation/adherence drop (relevant given ADHD — missed sessions are a signal, not a failure).

## Notes for Exercise Guide
Full exercise list this program uses, with the difficulty ladder and precautions:

| Exercise | Progression Ladder (easy → hard) | Precaution/Cue |
|----------|-----------------------------------|-----------------|
| Push | Wall push-up → Incline push-up → Knee push-up → Full push-up | Hands under shoulders, no flared elbows past ~45°, no neck craning. No injury history but this is the pattern most likely to expose shoulder discomfort in a true beginner — regress a rung immediately if felt. |
| Squat | Assisted squat (hand support) → Bodyweight squat → Tempo squat (3s eccentric) → Split squat (rear foot elevated on chair) | Knees track over toes, no valgus collapse. Given BMI ~30, keep depth to comfortable range early — do not chase full depth before control is there. |
| Hinge | Glute bridge → Single-leg glute bridge → Hip thrust (elevated, chair against wall for stability) | Chair used for elevation MUST be stable against a wall — flag as the one setup that needs a stability check given "fragile home." |
| Pull | Reverse snow angel → Band row → Band row w/ pause | If using a band: anchor to a fixed, load-rated point only (closed door hinge side is a common failure point — do NOT anchor to door handles or lightweight furniture). If no band, reverse snow angel alone is sufficient — do not treat it as optional. |
| Back extension | Superman hold → alternating arm/leg raise → pulses | Do not hyperextend the neck — eyes stay toward the floor. |
| Core | Dead bug → slow-tempo dead bug → hollow body hold (short holds only) | Keep lower back flat against the floor throughout — if it arches, the rep is too advanced. |
| Isometric | Wall sit → wall sit w/ heel raise → single-leg-assisted wall sit | Knee angle ~90°, weight in heels, stop if knee pain (not muscular fatigue) appears. |

General: no jumping/plyometric/ballistic movements anywhere in this program — protects joints (true beginner + BMI 30) and the fragile home/floor. No exercise requires equipment; the band is strictly optional.

## Notes for Nutrition Coordinator
- **Goal**: Recomposition, fat-loss-priority (BMI ~30.1). Moderate deficit recommended (~15-20% below TDEE) — not aggressive, since resistance training + protein need to preserve muscle during the cut.
- **Protein target**: 1.6-2.2 g/kg bodyweight/day → 82kg = **~130-180g/day**. This is the hard floor to protect during any deficit.
- **Training energy demand**: 3× 25-30 min bodyweight circuits/week at RPE 5-8 (moderate, not high-output — no loaded/ballistic work) + existing daily walks (already programmed, unchanged) — treat as light-moderate weekly training load for TDEE calc.
- **Build on existing MEALS structure** in schedule.html (Vietnamese home-cooked, VND cost-tracked, currently ~1720-1820 kcal/day [corrected — orig. draft estimate of 1900-2150 was wrong, verified by direct tally], ~126-132g protein/day flat) — adjust portions/macros to hit the protein floor above, don't replace the cuisine or cost tier.
- Sunday remains weigh-in day; judge 3-week trend, not single readings (existing convention, keep it).
